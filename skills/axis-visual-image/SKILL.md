# Axis visual image

Read references/creative-direction.md for production language, references/prompt-framework.md for visual completeness and references/vision-decomposer.md when analysing a provided visual. Add references/storyboards.md or references/characters.md only for that task.

Translate references into concrete framing, colour, lighting, texture and product/identity constraints. Separate reference roles and what not to copy. Use the agency art-direction and reference-plan templates. Preserve branded product details from supplied evidence.

Universal methodology only. Do not follow upstream automatic model-selection, parameter defaults or generation-cost assumptions. Provider documentation for other tools is not Melius documentation. Still briefs should state intention in prose. Read the local Melius adapter when packaging.

Adaptation changes: namespaced entry point, approved-concept prerequisite, universal visual direction, provider selection removed, human art-direction gate retained. upstream-SKILL.md records the original.

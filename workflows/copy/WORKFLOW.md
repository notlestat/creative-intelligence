# Copy and release content

Require an approved concept. Run `prepare <client> <project> copy`. Read `skills/axis-performance-creative/SKILL.md`; add `skills/axis-messaging/SKILL.md` only for a genuine proposition or voice issue.

Create 07_copy/copy.md with on-screen copy and timings, VO or an explicit no-VO decision, headline, primary text, CTA and alternate hooks where useful. Include the campaign or release sequence and a matrix covering only the approved deliverables. Preserve the approved mechanic and emotional intent.

No invented urgency, discounts, comparative superiority, savings, results or testimonials. Map every factual assertion to a source. Keep hooks meaningfully different while testing one variable at a time. Use the brand's tone, never an imported aggressive default. Verify current platform/placement specs against official documentation, distinguish hard caps from recommended lengths and note unknowns.

Set READY_FOR_REVIEW when complete. Copy travels in the production package and final asset approval; it is not proof of measured performance.

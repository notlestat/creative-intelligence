# Creative intelligence research

Read the intake, supplied source material and existing knowledge. Run `prepare <client> <project> research`. Use current read-only research tools and record provider or platform access limits.

For an artist, read `.agents/skills/axis-artist-intelligence/SKILL.md`, `axis-audience-research`, `axis-cultural-research` and `axis-competitor-intelligence`. For a brand, use `axis-brand-intelligence` with the same audience, culture and competitor modules.

Complete entity intelligence, audience research, cultural research, competitor research, creative references, signals, research summary and evidence log. Artist interpretation must remain separate from verified biography or author intent. Analyse lyrics only when the user supplied them. Treat credits and collaborators as unknown until sourced.

For visual-reference discovery, use Cosmos only when its tools are available and after reading [the Cosmos operating rules](../../references/cosmos.md). Call `cosmos_whoami` first. Search in small batches, inspect shortlisted images with `cosmos_view_images`, and expand only useful seeds. Record the Cosmos element or collection URL, original source and creator where available, intended visual role, what to study, what not to copy and any missing credit as UNKNOWN. Cosmos ranking, captions and save counts are discovery signals, not facts about the artist, audience or rights.

Do not create or modify a Cosmos collection unless the user explicitly asks. Keep a created collection private unless the user separately asks to publish it. Present the reviewed reference shortlist before concepts are developed.

FACT needs a source. OBSERVATION describes inspected material. INFERENCE names the evidence it interprets. HYPOTHESIS states how to test it. UNKNOWN records an unresolved point. Quotes stay short, exact and attributed. Do not turn a handful of fan comments into a broad audience truth.

Use `axis-signal-analysis` only after the source set is visible. A strong signal requires repeated, relevant evidence. Record counterexamples, dates, sample limits and inaccessible platforms. Set each complete research file to `READY_FOR_REVIEW`.

# Creative review and iteration

Run status and require all current creative approvals. Review against the exact production package used. Read the approved concept, treatment and shot list, then inspect actual files in 08_generations. Run `prepare <client> <project> review`.

Use references/review-schema.md and the review template. Inspect still quality and temporal qualities using available playback/frame tools. Never rate camera motion, continuity or audio from filenames or a single thumbnail. If unavailable, mark NOT_ASSESSED and request the missing review. No media generation or post-production is part of this phase.

Assess all fifteen criteria. For each asset record hash, observed timestamps, scores, classification and exact corrections. PASS is a creative recommendation, not human final approval. PASS WITH CHANGES cannot enter the final selection until the changed output is inspected and receives PASS.

Then apply the performance lens: does the first 1-2 seconds earn attention, is the action comprehensible, why should the audience care, what is sold, is proof needed, is the proposition clear and does the CTA fit? Preserve the distinctive mechanism while correcting ambiguity. Label performance expectations as judgment until real data exists.

If real Meta results are supplied, consult the locally installed axis-meta-context entry and its results reference only for diagnostic questions. Record delivery context, sample size, attribution window and confounders. Do not treat a generic benchmark as this client's result or automatically change the ad account.

Iteration must state change, preserve, expected benefit and acceptance test. Prompt-only corrections that preserve the approved shot can form a new take. Changes to concept, art, story or shot plan require renewed approval. Never overwrite prior generations or reviews; archive prior review versions inside 09_review/history and append decisions.

Ask the human to select final passing assets, record selected booleans and then obtain `APPROVE ASSETS`. This gate binds the actual asset hashes, package and copy. Do not infer approval from a high score.

# Axis storyboard
## Purpose
Plan the sequence so every frame communicates something necessary.
## Inputs
Approved idea and art direction, duration, format, copy, sound needs, assets, budget and distribution.
## Process
1. State the narrative change across the sequence.
2. Assign each frame a timestamp and purpose.
3. Specify camera, subject action, light, location, transition, audio and copy.
4. Remove frames that repeat a job.
5. Place editable placeholder frames on canvas.
## Evidence requirements
Claims in copy remain sourced. Reference frames retain provenance and usage notes.
## Outputs
Ordered storyboard frames and an editable visual board.
## Failure modes
Shot list without narrative, decorative transitions, impossible timing, generic slow motion, missing sound plan.
## Quality checklist
- Every frame has one purpose.
- Total timing is plausible.
- Transitions connect ideas.
- Storyboard approval is recorded before production.

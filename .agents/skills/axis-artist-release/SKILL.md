# Axis artist release
## Purpose
Build a coherent release world without forcing a standard album-campaign checklist.
## Inputs
Artist memory, release context, approved opportunity, music access, dates, collaborators and constraints.
## Process
1. Define the release world's central behaviour.
2. Choose relevant outputs from cover, identity, teasers, social, video, live, merch, collaboration or activation.
3. Set how the idea changes across time and format.
4. Protect artist fit at every review.
## Evidence requirements
Credits, dates, lyrics and artist statements remain sourced or supplied. Fan claims need observed evidence.
## Outputs
Release-world plan with chosen outputs, sequence, risks and approval points.
## Failure modes
Generic mysterious imagery, every channel by default, invented artist narrative, copying current genre aesthetics.
## Quality checklist
- The music and release context lead.
- Outputs share one world.
- Scope matches resources.
- Artist approval is distinct from manager or label input.

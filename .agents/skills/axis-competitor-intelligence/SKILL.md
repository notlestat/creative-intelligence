# Axis competitor intelligence
## Purpose
Show where a comparison set clusters and where the project might make a distinctive move.
## Inputs
Named alternatives, public sites, pricing, campaigns, content, reviews and access dates.
## Process
1. Define why each project belongs in the comparison set.
2. Capture positioning, audience, product, price, visual and content patterns.
3. Compare repeated behaviours across the set.
4. Identify whitespace as a question, not an automatic opportunity.
## Evidence requirements
Each factual cell has a dated source. Private or unviewed product details stay unavailable.
## Outputs
Visual matrix, cluster summary, meaningful differences and research gaps.
## Failure modes
Generic SWOT, invented weaknesses, feature parity thinking, using competitors as execution references.
## Quality checklist
- The sample boundary is named.
- Similarities and differences are both honest.
- Whitespace follows the evidence.
- Unavailable data is explicit.

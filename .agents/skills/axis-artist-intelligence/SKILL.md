# Axis artist intelligence
## Purpose
Understand the artist, the current release and the visual history that the next work must extend or challenge.
## Inputs
Artist-approved biography, release notes, user-supplied lyrics, catalogue, visual references, collaborators and constraints.
## Process
1. Separate enduring artist identity from the current release context.
2. Map genre, themes, tone, imagery, style associations and previous release patterns.
3. Analyse only lyrics the user supplies.
4. Mark every proposed meaning as interpretation, not author intent.
## Evidence requirements
Catalogue and credits need sources. Lyrics must be supplied by the user. Audience claims need observed evidence.
## Outputs
Artist memory with confidence, evidence and open questions.
## Failure modes
Invented lore, automatic lyric retrieval, genre stereotyping, treating collaborators as confirmed without credits.
## Quality checklist
- Biography and interpretation are distinct.
- Release-specific themes do not overwrite artist history.
- Rights and sensitive material are noted.
- Unknowns are usable questions.

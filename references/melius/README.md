# Melius documentation

The Axis package keeps universal production briefs as its approved source. For connected production, read [canvas-handoff.md](canvas-handoff.md) and then query the live Melius connector. Provider models, settings and prices change, so the runtime guide and model registry override any saved capability note.

Actual client or provider documents should remain local when confidential. Add local documents under `.local/melius/` if they must never be committed, then point the project intake at that path. Never store Melius credentials in a project.

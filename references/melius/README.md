# Melius documentation

Universal production briefs hold the approved creative direction. [The canvas handoff guide](canvas-handoff.md) describes connected staging. A saved guide does not establish current connector access, model availability, settings, or prices.

For connected work, inspect the live provider guidance and model registry before selecting settings. Staging does not authorise generation or credit spend.

Keep confidential provider documents under `.local/melius/` and reference that path in the project intake. Do not store credentials in project files.
